EviSeq: Source-Grounded Summarization with Composed Pretrained Encoders and Causal Decoders

Long-document summarization asks a model to shorten a source without losing the evidence that makes it useful. This becomes difficult when the source encoder and causal decoder come from separate pretrained checkpoints: matching their widths makes the tensors compatible but does not determine how source information should reach the generator. We present EviSeq, a source-grounded summarization system built around an Adaptive Full-Memory Residual interface. AFMR retains every visible source position, separates adaptable retrieval keys from aligned final-state values, and learns bounded source-priority adjustments. Copied cross-attention lets each decoder layer read this memory, while an offset-based copy route provides access to source wording and numbers. The model is trained with a single gold-token likelihood objective and evaluated with deterministic decoding. We compare it with fine-tuned decoder-only models and an encoder–decoder reference across long-document domains, examining source consistency, summary quality, component contributions, and encoder effects. Implementation tests support the executable design; held-out predictions and empirical comparisons remain pending.
