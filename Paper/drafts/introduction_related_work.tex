\section{Introduction}
\label{sec:introduction}

% Role: establish the task and the factuality--overlap distinction.
Long-document abstractive summarization asks a model to compress a source into a shorter text while preserving its salient content. In scientific, biomedical, book, and government documents, the compressed text must retain entities, numbers, and relations that can be supported by the source. This requirement makes factual support a separate target from lexical overlap: a fluent summary can resemble a reference while changing a quantity or relation. Prior work documents this distinction in abstractive summarization \citep{maynez2020faithfulness}.

% Role: state the interface gap created by independently pretrained components.
Standard sequence-to-sequence models learn source reading and target generation as one interface, with the decoder attending to encoder states \citep{sutskever2014sequence,bahdanau2015neural,vaswani2017attention}. Models such as T5, BART, and mT5 pretrain this interface jointly \citep{raffel2020t5,lewis2020bart,xue2021mt5}. A different setting arises when an embedding-oriented encoder and a causal decoder are reused from independent checkpoints. Their hidden widths, representation coordinates, tokenizers, and pretraining objectives need not agree. A width-matching projection resolves a shape constraint, but it does not specify which source representations, positions, or lexical forms should drive each generated token.

% Role: sharpen the technical challenge and bridge to the proposed interface.
Source access therefore has two coupled requirements. The interface must keep the source content available after truncation while assigning useful priority across depth, feature channels, and source spans. It must also expose lexical source forms without making a separate retrieval objective the authority for generation. Long-document attention and copying provide partial precedents for these requirements, but they do not by themselves determine how to allocate information between independently pretrained representation spaces \citep{cohan2018discourse,see2017get}. This paper treats that allocation as an interface question whose evidence must come from the same generation graph and matched comparisons.

% Role: give the method idea at the level needed to understand the questions.
We study this question with \EviSeq, whose proposed interface is \AFMRFull{} (\AFMR). \AFMR retains a full retrieval tensor for all visible source positions and an aligned final-state value tensor, then learns small, controller-conditioned adjustments along three axes. A depth route combines the final encoder state with the last four hidden-state taps around a final-state anchor. A cross-space feature route adapts the encoder representation to the decoder width while preserving the main projection path. A multi-scale route forms a shared additive prior from overlapping source-token windows at lengths 32, 128, and 512 in the base profile. The decoder reads the resulting tensors through a copied cross-attention block in every layer; refined representations shape keys, while final-state representations provide values. A grounded-copy route aligns source and decoder-token offsets, combines lexical and contextual keys, and marginalizes repeated source token IDs. The design retains all visible source positions and requires no evidence labels at inference.

% Role: define the evidence boundary and the locked comparison protocol.
The graph is trained with the gold-token mixture cross-entropy used for generation. Training consists of one interface warm-up epoch followed by full fine-tuning, and official generation uses one beam with sampling disabled. We evaluate the same preprocessing, splits, source and target budgets, and training budgets for \PubMed, \ArXiv, \BookSum, and \GovReport. The comparisons include fine-tuned decoder-only controls and fine-tuned \TfiveGemma. Implementation and unit-test evidence can establish tensor, masking, gradient, checkpoint, and inference invariants, but the four-dataset prediction files and quality scores are not available at draft time. \AFMR is therefore a testable hypothesis here; this paper makes no claim of a \Rouge or factuality improvement before the locked runs.

% Role: pose the locked four-question chain.
Across \PubMed, \ArXiv, \BookSum, and \GovReport, we ask four linked questions:

\begin{itemize}
  \item \textbf{RQ1 (factual-support signal):} Does \EviSeq reduce a source-unsupported-content signal relative to fine-tuned decoder-only LLMs on all four datasets? We operationalize the automatic comparison with native \AlignScore consistency and its direction-transformed $H=1-C$ value; a typed entity/number/relation error claim requires a separate adjudicated audit.
  \item \textbf{RQ2 (quality):} How does \EviSeq change \Rouge-1/2/L and \BERTScore relative to the same decoder-only controls and fine-tuned \TfiveGemma under matched records, budgets, preprocessing, and decoding, with each model's native input serialization documented, on all four datasets?
  \item \textbf{RQ3 (mechanism):} Which of the encoder, \AFMR bridge, and grounded-copy route is necessary for the observed behavior? Run no-encoder, no-bridge, and no-grounded-copy controls on all four datasets with a fixed decoder and matched training budget.
  \item \textbf{RQ4 (portability):} Does the same interface transfer across a bidirectional embedding encoder, a causal encoder, and a larger embedding encoder, and how do directionality and capacity affect quality and factuality? Run \PPLXEmbed as the anchor plus \QwenCausal, \QwenEmbed, and \NemotronEmbed variants on all four datasets.
\end{itemize}

% Role: make the causal bridges between the questions explicit.
RQ1 tests whether source grounding changes an automatic source-support signal; RQ2 tests whether any difference is accompanied by a change in reference overlap or semantic similarity; RQ3 tests which routes contribute to the observed benchmark behavior; RQ4 tests whether that behavior persists across the registered encoder choices, whose directionality and capacity differ. For RQ1, the primary automatic signal is native \AlignScore consistency, where higher is better; $H=1-C$, with $C=\AlignScore_{\texttt{nli\_sp}}$, is reported only as a direction-transformed hallucination-oriented score, where lower is better, and is never treated as a calibrated probability. RQ2 uses \Rouge-1/2/L F1 and \BERTScore-F1 as complementary overlap and semantic-similarity measures. Any interpretation of these measures remains conditional on the held-out predictions and paired uncertainty intervals.

% Role: state contributions without converting planned evidence into results.
The paper makes three contributions. First, it formulates \AFMR as a constrained full-memory interface for composing a pretrained encoder with a causal decoder, with separate key-side adaptation and final-state values. Second, it integrates controller-conditioned depth, cross-space feature, and multi-scale span adjustments with a grounded-copy route while retaining the single gold-token generation objective. Third, it specifies a reproducible four-dataset evaluation contract that separates source-support signal, overlap quality, component contribution, and encoder portability, together with the diagnostics and uncertainty estimates needed to interpret those questions. These contributions define an experimentally falsifiable interface; they do not assert that any component is necessary or that the complete system is superior before the planned comparisons are run.

\section{Related Work}
\label{sec:related-work}

% Role: position AFMR against jointly trained and composed encoder--decoder systems.
\paragraph{Encoder--decoder interfaces and checkpoint composition.}
Sequence-to-sequence learning and attention established the encoder--decoder division between source representation and autoregressive generation \citep{sutskever2014sequence,bahdanau2015neural,vaswani2017attention}. T5, BART, and mT5 make this division part of joint pretraining, so their source and target representations are optimized together \citep{raffel2020t5,lewis2020bart,xue2021mt5}. Other work reuses decoder-only checkpoints for representation learning, including LLM2Vec and Generative Representational Instruction Tuning \citep{behnamghader2024llm2vec,muennighoff2024grit}; LaMaTE places a language-model encoder in a translation system, and Qwen3 Embedding provides an embedding-oriented model family \citep{luo2025lamate,zhang2025qwen3embedding}. \TfiveGemma is a close reference for arranging modern language-model components as an encoder--decoder system \citep{zhang2025t5gemma2}. \AFMR borrows the goal of reusing pretrained components and the decoder's cross-attention interface, while focusing on the post-composition allocation problem that remains when the checkpoints were not released as a matched encoder--decoder model. We make no novelty claim for generic checkpoint reuse or for cross-attention itself.

% Role: connect long-document methods to the full-memory design distinction.
\paragraph{Long-document source access.}
Long-document summarization has used hierarchical or discourse-aware attention to represent documents at more than one granularity \citep{cohan2018discourse}. These methods motivate reasoning over local and broader source regions, but they leave a design choice about how a composed model should turn regional preference into decoder retrieval. \AFMR uses overlapping token windows at several scales only to construct a soft source prior; the decoder still receives retrieval and aligned value tensors for every visible source token. The resulting interface can be compared with no-bridge and matched encoder controls without treating hard selection, sentence slots, or source compression as part of the proposed method.

% Role: distinguish grounded copying from pointer and coverage mechanisms.
\paragraph{Copying and source coverage.}
Pointer-generator networks combine vocabulary generation with an attention-based copy distribution, and coverage mechanisms can discourage repeatedly attending to the same source content \citep{see2017get}. \AFMR adopts the useful generation--copy decomposition but adapts it to independently tokenized components: character-offset overlap provides sparse source-to-decoder alignment, contextual and lexical features form copy keys, and repeated source occurrences are marginalized by decoder token ID. The copy route is trained through the same token-level mixture likelihood as language-model generation. \AFMR does not use a separate coverage loss and does not interpret copying as factual verification; a source token can still be selected in the wrong relation or role.

% Role: separate factuality evidence from lexical and semantic similarity metrics.
\paragraph{Factuality and summary evaluation.}
\Rouge measures reference overlap \citep{lin2004rouge}, while \BERTScore measures contextual semantic similarity between generated and reference texts \citep{zhang2020bertscore}. Work on faithfulness and evaluation has shown why such measures should not be treated as direct factuality guarantees \citep{maynez2020faithfulness,fabbri2021summeval}. We therefore use \AlignScore as the primary automatic factual-consistency signal, report its native consistency direction, and disclose $H=1-C$ for $C=\AlignScore_{\texttt{nli\_sp}}$ only as a lower-is-better diagnostic \citep{zha-etal-2023-alignscore}. \AlignScore remains a learned proxy that can miss cross-sentence or domain-specific errors, and \BERTScore is not a hallucination detector. The evaluation contract consequently pairs these metrics with prediction diagnostics and, where available, a manual factual-error audit.

% Role: close Related Work with the precise distinction and evidence boundary.
Taken together, these lines of work supply the interface primitives used by \AFMR: source--target attention, multi-scale source reasoning, and vocabulary--copy mixtures. \AFMR combines them at one full-memory boundary, adds bounded controller-conditioned residuals for encoder depth, cross-space features, and source-span priority, and trains the complete graph with gold-token cross-entropy. Its RQ3 ablations test whether those additions matter under a fixed decoder and matched budget, while RQ4 tests transfer across the specified encoder families. The literature motivates these choices; only the locked four-dataset experiments can support claims about quality, factual support, component contribution, or portability.
