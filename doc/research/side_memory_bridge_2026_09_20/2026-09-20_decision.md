# Four bridge directions after the region/slot failures

## Context

The matched PubMed runs for the recent region/slot residual bridges were:

| Variant | ROUGE-1 | ROUGE-2 | ROUGE-L |
|---|---:|---:|---:|
| `evidence_slots` | 49.427 | 21.975 | 45.750 |
| `adaptive_topdown` | 49.494 | 21.994 | 45.779 |

Both fell below the user's `w/o bridge` control. Those modules compressed source information and injected a residual into the token-key route. The next designs should therefore preserve the original token K/V as an independent path.

## Four distinct hypotheses

### 1. Gated side-memory cross-attention — first choice

Build `E` with 16–32 compact evidence tokens from `H0`. At decoder cross-attention, retain the existing token route:

`C_token = Attn(Q, K0, V0)`

Then add a separate side read:

`C_mem = Attn(Q, K_E, V_E)`

and update the decoder with `H <- H + tanh(alpha_l) * C_mem`, with `alpha_l=0`. Do not add `C_mem` to `K0` or `V0`; do not pass its scores to grounded copy. This directly tests whether compact global evidence is useful when it cannot corrupt lexical token matching.

Evidence: Flamingo's fixed resampler and zero-initialized gated cross-attention; GTCA's checkpoint-compatible side path.

### 2. Explicit mixture of two banks

Keep the two cross-attention contexts separate and mix them with a bounded gate:

`C = C_token + sigmoid(g_l(h_t)) * C_mem`.

Unlike concatenating `[K0; K_E]`, this does not force token and memory entries to compete in one softmax. Unlike a residual key bridge, `C_mem` has its own K/V pair. Use a per-layer gate initially zero or a very small negative bias, and log its mean, variance, and token-position correlation.

Evidence: Flamingo and GTCA support gated side injection; Perceiver-style resampling supports a fixed-size bank. The mixture form is an AFMR hypothesis, not a result reported by those papers.

### 3. Landmark-guided exact-token retrieval

Create one normalized landmark per source block. For each decoder query, score landmarks to obtain a soft block distribution, then read exact `K0,V0` token slices under that distribution. Add the retrieved context through a bounded side gate while retaining ordinary full-source attention as a fallback. Copy remains fully token-level.

Evidence: LongT5's transient global tokens and Landmark Attention's block selection. This differs from the failed region-query residuals because the compact representation routes to untouched token values; it does not rewrite all token keys.

### 4. Dual-timescale recurrent/compressive memory

Encode fixed source chunks into a fine bank and update a small global bank recurrently. The decoder reads both side banks, while the original token bank remains intact. Use CE-only first; no reconstruction loss, candidate generation, or BPTT across document examples. This is the highest-risk but most different option.

Evidence: Recurrent Memory Transformer, Compressive Transformer, and HMT. The papers support retaining multiple time scales, but not an AFMR score improvement.

## Recommended experiment order

1. Run direction 1 with `E=32`, rank 256, one side cross-attention in every fourth decoder layer, tanh gate initialized at zero, output RMS cap 0.10.
2. If direction 1 is non-dormant but does not improve validation ROUGE, run direction 3 with soft landmark routing and full-token fallback.
3. If direction 1 helps but destabilizes R-1/R-L, run direction 2 with a smaller per-layer gate and separate context normalization.
4. Run direction 4 only if validation documents are long enough to show a measurable cross-block deficit.

## Required diagnostics

- Native-token attention output norm versus side-bank output norm.
- Gate mean/standard deviation by decoder layer and target position.
- Difference in logits when the side bank is zeroed at inference.
- Grounded-copy mass and copied-token precision with side bank on/off.
- Validation ROUGE-1/2/L with identical seed, checkpoint, data, and CE objective.

## Claim boundary

These papers establish architectural precedents for compact memory and controlled side injection. They do not establish that any proposed AFMR variant will beat `eviseq_new`, T5Gemma, or the current `w/o bridge` score. The claim must be based on a matched validation-selected test run and the ablation that zeroes the side bank.
