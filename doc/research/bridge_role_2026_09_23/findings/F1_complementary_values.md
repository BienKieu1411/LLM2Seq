# F1: XOV is an untested value-construction hypothesis

Status: mechanism grounded; task effectiveness insufficient evidence.
Sources: ../sources/01_transformer.md, ../sources/02_convseq.md,
../sources/03_primer.md, ../sources/04_convbert.md, ../sources/09_local_code.md.

Cross-attention learns retrieval and projected values. Ordered lexical features
in decoder tokenization can be supplied as a residual to those values without
another source-selection algorithm. Contextual encoders and lexical copy may
already make the signal redundant. XOV has not been run per user correction;
its existence in Git must not be treated as negative experimental evidence.
