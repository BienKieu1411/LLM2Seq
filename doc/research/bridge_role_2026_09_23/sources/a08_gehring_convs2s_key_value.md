# A08 — Gehring et al. (2017), point information in attention values

- **Primary source:** Jonas Gehring, Michael Auli, David Grangier, Denis Yarats, Yann Dauphin, “Convolutional Sequence to Sequence Learning,” ICML 2017, PMLR 70, https://proceedings.mlr.press/v70/gehring17a/gehring17a.pdf
- **Relevant evidence:** Section 3.3, Eq. (2), defines the conditional input as a weighted sum of `z_j^u + e_j`, while the attention scores use the encoder output `z_j^u`. The authors state that adding `e_j` was beneficial and describe it as point information about the source element (PDF pp. 3 / HTML lines 212–257).
- **What it supports here:** A value-only, position-preserving lexical signal can in principle complement contextual encoder states: keys remain contextual `z`, while values receive a pointwise source embedding. The historical XOV route is a modern, order-aware version of this idea: decoder-token lexical embeddings are convolved and reverse-scattered into values.
- **Limitations and contrary evidence:** This is a convolutional encoder–decoder trained from scratch on translation and Gigaword, not PPLX→Qwen with grounded copy, RMSNorm, or GQA. It does not establish that a copied-token lexical residual helps a pretrained contextual encoder, and it does not preserve this repository's copy route when `value_memory` is reused by `encode_source`.
- **Use in verdict:** Treat this as a mechanistic precedent only. It justifies an XOV audit, not a predicted ROUGE gain; the audit must separately test whether the ordered lexical residual changes generation beyond the existing copy head.
