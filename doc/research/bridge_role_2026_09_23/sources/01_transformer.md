# S01 — Attention Is All You Need

URL: https://arxiv.org/html/1706.03762v7
Authors: Vaswani et al. Venue/year: NeurIPS 2017. Accessed: 2026-09-23.
Type: primary research. Credibility 5/5; recency 1/5; advocacy risk low.
Verified excerpt, section 3.2: “The output is computed as a weighted sum of the values”.

Sections 3.2–3.3 define attention and position-wise projections/FFNs. This
supports the distinction between constructing features and retrieving values.
It does NOT establish that contextual encoder states lack phrase information.
Linear absorption without intervening normalization is our algebra, not a
performance result from this paper.
