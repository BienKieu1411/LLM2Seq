# S07 — Position-Agnostic Pre-Projection for Transformer Attention

URL: https://arxiv.org/html/2604.10791v1
Author: Chirag Shinde. Date: 2026-04-12. Accessed: 2026-09-23.
Type: primary preprint. Credibility 2/5; recency 5/5; advocacy risk medium-high.
Verified excerpt, limitations: “500-sample evaluations”.

Studies nonlinear pre-projection and an attention bypass with frozen Pythia
backbones. This is a limited probe, not full fine-tuning at our scale. Existing
AFMR already contains a nonlinear residual, and a bypass would violate the
current scope. Do not use headline relative gains as a justification for a new
MLP bridge here. Excluded as the main recommendation.
