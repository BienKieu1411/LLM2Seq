## Main-figure storyboard

**Title:** *Performance as more source text becomes visible.*

Use a two-row × two-column full-width figure. Columns are PubMed and arXiv. Top row: ROUGE-L; bottom row: SCALE, labelled as an automatic source-support score. x-axis: a nominal word budget, implemented as the longest **sentence-aligned prefix not exceeding that budget**, supplied identically to every system on the same held-out documents; report actual mean visible words at each tick. Select feasible budgets only after tokenizer/window audit. Lines: SEAM, T5Gemma2, and one decoder-only reference with completed predictions. Add 95% document-bootstrap intervals, N, and a caption that states all curves use the same document subset. Put AlignScore replication in the appendix; show any contradiction rather than choosing the friendlier source metric. Add BookSum/GovReport replications in the appendix once their runs exist, or expand the main figure only if it remains legible.

For every document and budget, generate anew with the same checkpoint and deterministic decoding. Keep the target reference and the *full original source passed to evaluators* fixed across budgets. Record the exact text actually visible to each system, token counts, generated length, and any truncation. Avoid a line endpoint reconstructed from the existing aggregate table: the matched subset and scoring protocol may differ. Make both a pilot (PubMed, SEAM versus T5Gemma2) and a full figure (PubMed/arXiv with decoder-only reference) explicit stages. The systems differ in size and pretraining; the plot describes their empirical response, not a capacity-controlled architecture effect.

**The figure can fail productively.** If SEAM does not gain relatively with source budget, the paper should say so; the result narrows claims about long-source access. If quality improves but source-support metrics do not, say the dimensions diverge. The curve itself cannot attribute an effect to the bridge or copy head.

## What the literature does and does not establish

[Ravaut et al. 2024](https://aclanthology.org/2024.acl-long.153/) study context utilization and source position in LLM summarization, while [LongT5](https://aclanthology.org/2022.findings-naacl.55/) studies scaling input length. These support measuring a source-budget response, not predicting its direction for SEAM. [Wan et al. 2025](https://aclanthology.org/2025.naacl-long.442/) show that position/order and automatic faithfulness judgments interact; [Rahimi et al. 2025](https://aclanthology.org/2025.findings-emnlp.846/) challenge lexical source-position attribution. These make a position-intervention figure valuable but harder to interpret.

[Guo and Vosoughi 2023](https://aclanthology.org/2023.emnlp-main.984/) document output-length bias in summarization metrics. [Bishop et al. 2024](https://aclanthology.org/2024.lrec-main.941/), [Wu et al. 2024](https://arxiv.org/abs/2309.07382), and [Mujahid et al. 2026](https://aclanthology.org/2026.acl-long.1472/) give independent reasons to control source context and be cautious with long-document factuality metrics. [LongEval](https://aclanthology.org/2023.eacl-main.121/) motivates a small human clause-level check if a factuality claim is central. No consulted paper validates an expected SEAM advantage.

For the conditional copy figure, [SpanCopy](https://aclanthology.org/2023.codi-1.9/) and [PROM](https://aclanthology.org/2024.lrec-main.1148/) mean that copying itself is not novel. The differentiator to test is copying across the actual independently pretrained tokenizers, not general entity string overlap. A character-span precedent exists in another task ([Nguyen et al. 2026](https://arxiv.org/abs/2601.11865)).

## Local-data boundary

The existing manuscript has a method architecture graphic and aggregate results, with pending arXiv decoder-only, BookSum, GovReport, and some ablations. Evaluation scripts can emit per-example details, but no test predictions or dataset records were found here. Consequently this report specifies an empirical plan; it does not claim that the proposed curve exists or that SEAM wins it. Source notes, evidence limits, and refresh tasks are in this directory.
