# Wu et al. 2022 — IDPG

Source: https://aclanthology.org/2022.naacl-main.403.pdf  
Venue: NAACL-HLT 2022.

## Verbatim evidence

- IDPG introduces a “lightweight and trainable component” that generates a
  prompt for each input instance.

## Relevance and limitation

IDPG is evidence that a controller can generate input-dependent adaptation
parameters. Its main experiments are NLU prompt tuning, not cross-attention or
summarization, so it provides weak support for the hyper-bridge alone.
