Verified excerpt, section 7.2: “optimized solely for output length”.

Length-only GRPO has dataset-dependent content outcomes and qualitative factual errors. A maximum-only request can reward responses far below the desired size. This supports proximity-aware wording and simultaneous content evaluation; it does not prove which reward is best for SEAM.
